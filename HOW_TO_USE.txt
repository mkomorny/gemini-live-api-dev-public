HOW TO USE: gemini-live-api-dev
====================================

PURPOSE
  Build and migrate high-performance, real-time, bidirectional audio, video,
  and text streaming applications using the Gemini Live API over WebSockets.

CAPABILITIES
  - Implement bidirectional audio/video/text streaming using google-genai (Python) or @google/genai (JS/TS).
  - Use and configure Gemini 3.8 Live models (gemini-3.8-live, gemini-3.8-live-extended-thinking).
  - Configure background reasoning (thinking_level, non-blocking tools, and interaction_status tracking).
  - Implement live streaming translation (gemini-3.5-live-translate-preview) and live transcription (gemini-3.5-transcribe-live).
  - Manage real-time sessions: client-side Hybrid VAD (audioStreamEnd), context window compression, session resumption, and interruption signals.

USE CASES
  - "How do I build a real-time voice assistant with Gemini 3.8?"
  - Migrating from deprecated SDKs or older Live API models (e.g. gemini-2.0-flash-live-001) to gemini-3.8-live.
  - "How can I make my voice agent perform complex background reasoning while speaking fillers?"
  - Building low-latency streaming transcription or speech-to-speech translation tools.

IDEAS
  - Integrate Live API with partner tools like LiveKit, Pipecat, Fishjam, or Stream.
  - Implement hybrid voice activity detection (VAD) on the client side to reduce latency.
  - Create secure client-side apps using Ephemeral Tokens for serverless authentication.
